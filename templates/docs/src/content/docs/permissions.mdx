cv4pve-TOOL works through the API, so what it can do is exactly what its account is allowed to.
Use a dedicated user with an API token rather than `root@pam`.

## Create the user and the token

<ApiTokenSetup
  tool="cv4pve-TOOL"
  user="TOOL@pve"
  role="CV4PVETOOL"
  tokenId="TOOL"
  privileges={['VM.Audit', 'TODO']}
/>
