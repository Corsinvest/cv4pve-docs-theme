cv4pve-TOOL runs **outside the cluster** (on your workstation, a management VM or a scheduled job)
and talks only to the Proxmox VE REST API on port 8006. Nothing is installed on the nodes.

## First run

Create a dedicated user and API token first: see [Permissions](/cv4pve-TOOL/permissions/). Then point
the tool at any node:

```bash
cv4pve-TOOL --host=pve1.local --api-token='user@pve!token=<uuid>' TODO-command
```

Several nodes, username and password, certificates and keeping the options in a file: see
[Connection](/cv4pve-TOOL/connection/).
