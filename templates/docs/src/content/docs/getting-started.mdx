cv4pve-TOOL runs **outside the cluster** — on your workstation, a management VM or a scheduled job —
and talks only to the Proxmox VE REST API on port 8006. Nothing is installed on the nodes.

## Connect to the cluster

Create a dedicated user and API token first — see [Permissions](/cv4pve-TOOL/permissions/). Then:

```bash

```
